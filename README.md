Teto — це багатофункціональний Telegram-бот, створений на Python. Він поєднує можливості штучного інтелекту, інтерактивного спілкування та різноманітних розважальних функцій.

Основою спілкування є Google Gemini 2.5 Flash, який дозволяє Тето відповідати на повідомлення користувачів, підтримувати діалог і створювати більш природне спілкування. Для збереження контексту використовується власна система пам'яті на базі SQLite, яка зберігає історію повідомлень та налаштування користувачів.

Окрім спілкування зі штучним інтелектом, Тето має багато додаткових можливостей (кнопки): перегляд погоди, випадкові передбачення, генерацію зображень, історичні факти, перевірку наголосів, музичну функцію та слово дня. Також реалізована підтримка голосових повідомлень із використанням Whisper.

Для створення більш живої атмосфери бот може самостійно надсилати випадкові повідомлення та GIF, підтримуючи активність навіть без безпосереднього звернення користувача. Передбачена й система відгуків, завдяки якій користувачі можуть ділитися своїми пропозиціями та зауваженнями.

Проєкт розробляється з використанням Python, aiogram, SQLite та зовнішніх API. Його розвиток передбачає поступове вдосконалення функціональності, оптимізацію роботи, покращення системи пам'яті та розширення можливостей штучного інтелекту.

Teto — це особистий проєкт, який поєднує програмування, експерименти зі штучним інтелектом та бажання створити цікавого цифрового співрозмовника.
